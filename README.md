# 宠芽 Petbud

> 从一颗蛋开始，养出只属于你的小伙伴。

**设计基线 v0.1 · 2026-11-04 · 中文开发规格**

Petbud 是以屏幕为主体、可随身携带的电子宠物：从魔法蛋出生，经历身体发育与习惯形成，回应呼唤，陪主人散步，与其他宠物交朋友、互赠物品并积累共同回忆。它的反应由状态、性格、经历与受控随机性共同决定；包含极低概率永久死亡及免费重新领蛋。

本仓库当前交付**产品与技术设计、接口草案、配置样例、文档校验工具，以及可本机运行的浏览器互动原型**。固件、App 和后端尚未实现。参数属于候选基线，未经实机、用户或统计验证，不代表商业承诺。

## 先体验原型

已提供[浏览器模拟器 Alpha 0.6](simulator/README.md)：选蛋、概率动作、喂养、扔球、加速成长、模拟社交及本地存档。运行 `cd simulator` 后执行 `python3 -m http.server 8080 --bind 127.0.0.1`，打开 http://localhost:8080。猫、龟内置本地三维角色，支持分龄、睡眠和距离驱动步态；无需Runway、模型密钥或硬件。功能边界见模拟器说明。

## 核心约束

- 基础生命与动作在本地执行，断网可玩；LLM 不决定健康、死亡、积分、库存或交易。
- 行为是有上下文的概率选择；安全边界、交易一致性与数据恢复使用确定性逻辑。
- 死亡机制必须实现并能在仿真中测试；数值未校准前，试用构建以影子模式运行死亡采样，正式启用有明确发布门槛。
- 会员专属蛋为确定性权益，普通宠物拥有完整养成与社交；治疗和重新领蛋免费。
- 首版手机辅助定位，宠物本体 IMU 感知步行，BLE 发现同类；独立 GNSS/蜂窝作为后续 SKU 评估。
- 首版屏幕优先，可动耳并行做样机对照，未验证前不阻塞主线。
- 一台设备同一时刻只有一只活宠和一个权威写入者；不覆盖原有宠物来领取会员宠物。

## 从哪里开始开发

先实现 `petcore` 的宿主机版本与批量仿真，再实现设备上的完整单宠闭环，随后两台设备社交，最后接 App、云端和支付。详见[实施计划](docs/09-roadmap.md)。

建议未来代码目录：`core/`（可移植 C++）、`firmware/`（ESP-IDF）、`simulator/`、`app/`（Flutter）、`server/`（模块化单体）、`assets/`。本次不创建这些空壳或声称可运行。
