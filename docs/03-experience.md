# 交互、美术与音频规格

## 信息架构

设备：首页生活场景／快捷照顾／玩具／散步／朋友／状态／设置。App：宠物／回忆／朋友／设备／账户。设备不承担长文本编辑；命名可在设备预设/简单输入或 App 完成。

首页默认无常驻数值条。单击宠物轻触，长按打开照顾；点击球进入扔球，边缘按钮呼出菜单。实体短按唤醒/返回，长按语音需在按键方案实测后确定，超长按电源独立处理。顶部触摸区用于抚摸；放包模式锁触摸，实体键解锁。

## 首次引导

开机选语言及静音 → 可跳过联网 → 三蛋选择 → 确认 → 5—15秒破壳 → 触摸回应 → 命名 → 喂食 → 自由生活。每步有 checkpoint，重启不换 pet_id、花色或 seed。会员入口不遮挡三普通蛋。

命名候选 1—12 个可见字符，实际按 grapheme 计长，拒绝控制字符；UTF-8 持久化，显示字体覆盖不足时提供替代显示，不破坏原名。改名有明确确认，昵称学习与记忆更新。

## 场景与角色

2D/2.5D 正面略俯视房间，统一逻辑坐标 320×240，屏幕适配时留安全边界；最终分辨率由 EVT 确定。场景含睡垫/窝、饭碗、玩具，宠物保持视觉主体。日夜只影响光照与作息，不要求用户夜间照顾。

角色资产分物种、品种、阶段、花色层。成年体型不超过可活动区，成长通过比例、动作与贴图共同表现。阶段切换插值或短过渡，不瞬间换成陌生角色。

首批每物种至少覆盖：idle呼吸/眨眼、看向、走、跑或慢爬、坐卧、吃喝、睡醒、开心、拒绝、疲劳、不适、治疗、死亡静帧。狗有叼球，猫有伏低扑拍，龟有探头缩头和顶球。每类加入可重用微变体，动作数量不是生命感验收替代品。

资源清单必须包含 asset_id、species、stage、action、variant、fps、duration、pivot、collision_box、interrupt_markers、audio_cues、license。动画只订阅 core 意图，不反向决定宠物是否生病。走路根位移与碰撞由引擎控制，避免脚滑和穿墙。

## 玩球

按住球拖动显示方向和力度，释放发射；方向采用明示箭头，避免用户猜弹弓还是推球。v = clamp(k*drag_distance, vmin, vmax)，对速度限幅；碰壁法线反射并乘恢复系数，滚动摩擦逐渐减速，小速度归零。固定步长、扫掠碰撞避免高速穿墙。球不能进入窝/饭碗等不可达区域；边界失败自动回收。

宠物选择观察、追、扑、等待、带回；反应延迟和命中率由阶段、疲劳、兴趣决定，有随机扰动。球无物理随机跳变，随机的是宠物策略与动作。强烈摇晃不提升奖励，不鼓励用户抛掷设备。

## 声音与语音反馈

短叫、呼噜、脚步、睡眠、相遇招呼建立统一音色。默认低音量、可全静音、夜间免打扰；用户操作和主动行为分别设限。设备用叫声及短气泡，开放语音理解不要求宠物长篇说人话。

接收到呼唤后先以本地看向/耳动确认，再选择回应。未识别时不扣亲密度。网络超时用本地反应结束，不持续转圈等待。录音中有可见标记；麦克风关闭不应影响核心养成。

## 动耳映射

若安装：注意=轻抬、开心=短摆、困倦=下垂。身体情绪是主状态，耳朵为冗余表达。两耳可联动单自由度，独立双耳不列首版必需。过流/卡住立即停机，静音/收纳模式默认禁动作。

## 死亡和纪念

不使用惊吓声、血腥或失败评分。一次温和告知和静帧，可跳过。原因使用事件真实归类，健康突发不编造漏喂原因。回忆册只引用真实经历；可导出纪念卡，默认不公开位置与主人身份。免费新蛋由用户主动领取，无倒计时促销。

## 体验验收

新用户能独立完成选蛋、喂食、扔球、静音；听障用户可凭屏幕理解重要事件；不依赖颜色单独传达健康。邀请用户比较同种不同养法宠物，记录他们能否描述具体习惯，而不是告知“有差异”后询问认同。
